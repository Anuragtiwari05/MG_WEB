MG Motor Mumbai — Dealership Website

Live demo: https://mgmotors-gmg.netlify.app/

A modern, responsive car dealership website built with Next.js. It features a car catalogue, test drive and service booking flows, a showroom locator, testimonials, and an FAQ section.

✨ Features
Car Catalogue — Browse a lineup of car models with pricing, specs, and category filters (SUV, Hatchback, Electric).
Test Drive Booking — Interactive form to schedule a test drive by model, location, date, and time slot.
Service Booking — Flow for booking maintenance/service appointments.
Location Finder — Showroom details with addresses, contact numbers, and map links.
Testimonials Section — Customer review carousel.
FAQ Section — Expandable Q&A component.
Contact Widgets — WhatsApp and click-to-call integration.
SEO Optimised — Structured metadata, Open Graph tags, and Twitter card support.
🛠️ Tech Stack
Framework: Next.js (React)
Hosting: Netlify
Image Optimisation: Next.js Image component
🔗 Site Structure
/ — Home
/about — About page
/cars — Car listing
/cars/[model] — Individual car detail pages
/locate-service-centre — Service booking
/locations — Location finder
/contact-us — Contact page
/privacy-policy — Privacy Policy
/terms-and-conditions — Terms & Conditions
🚀 Getting Started
bash
# Clone the repository
git clone <your-repo-url>
cd <project-folder>

# Install dependencies
npm install

# Run the development server
npm run dev

Open http://localhost:3000 to view it in your browser.
